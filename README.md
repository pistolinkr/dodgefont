# dodgefont

브라우저에서 폰트를 만들고, 스타일과 웨이트 위계를 입혀 macOS·Windows용 OTF 패밀리로 바로 내보내는 정적 웹앱.

- **스타일 레시피 30종** — 레퍼런스(인스타 저장 게시물)에서 뽑은 성격을 한 번에: 스위스 그로테스크, 디돈, 팻페이스·우드타입, 마커·붓, 캘리그래피 태그, 픽셀 LED·도트 매트릭스·CRT, 그리드 모듈러, 버블, 멜팅 드립, 컷페이퍼 스텐실, 3D 익스트루드, 하프톤, 샌드 디졸브, 키네틱 바운스, 네온, 모노 타자기, 컨덴스드·와이드, 울트라 씬, 한글 고딕·명조·이탤릭·붓·둥근
- **엔진** — 아웃라인(베이스 폰트 변형) · 모듈러(그리드 스냅) · 픽셀(격자 에디터: 사각/원/다이아/스캔라인/세로줄/십자 모듈)
- **스타일** — 굵기, 폭, 높이, 기울기, 라운드, 자간, 펜 대비(각도), 러프 엣지, 바운스, 모노스페이스, 모서리
- **이펙트** — 아웃라인, 인라인, 스텐실, 섀도, 3D 익스트루드, 멜팅 드립, 하프톤, 샌드 디졸브
- **위계** — 웨이트 패밀리(베이스 획 두께에 맞춰 자동 보정), 이탤릭 세트, 타입 스케일 역할(Display–Caption)
- **베이스** — 라틴 18종 + 한글 5종(나눔고딕·나눔명조·검은고딕·도현·나눔손글씨 붓), 직접 업로드
- **문자 세트** — 라틴, 라틴 + 한글 KS X 1001 2,350자, 베이스 전체
- **내보내기** — 맥용/윈도우용 ZIP(OTF + 설치 스크립트), 단일 OTF, 프로젝트 JSON

빌드 없음: `python3 -m http.server` 후 `index.html`. 확인: `node check.mjs`.
라이브러리: opentype.js, clipper-lib, JSZip (`vendor/`).
